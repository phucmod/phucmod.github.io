💡 Mẫu lệnh hỏi AI

Copy các mẫu này rồi dán vào khung chat AI:

🐞 Tìm lỗiCode mình báo lỗi [dán lỗi]. Đừng sửa giúp, hãy hỏi mình 3 câu gợi mở để mình tự tìm ra nguyên nhân.
📚 Hiểu khái niệmGiải thích [vòng lặp for / hàm / mảng...] bằng 1 ví dụ đời thường, rồi cho mình 1 bài tập nhỏ để tự thử. Đừng đưa lời giải.
🔍 Nhận xét codeĐây là code mình tự viết: [dán code]. Chỉ ra 2 điểm có thể cải thiện về cách đặt tên hoặc cấu trúc, đừng viết lại cả code.
🧩 Chia nhỏ dự ánMình muốn làm [ý tưởng]. Hãy chia thành 5 bước nhỏ, mỗi bước một câu, không viết code.
🎨 HTML / CSSMình muốn tạo hiệu ứng [mô tả]. Gợi ý các thuộc tính CSS nên tìm hiểu, đừng đưa code hoàn chỉnh.
